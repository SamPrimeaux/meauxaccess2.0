## 🚀 **How to Rebuild Pages**

### **Option 1: Via Admin Dashboard** (Recommended)

1. Go to: `https://www.meauxbility.org/admin`
2. Navigate to **"📄 Content Management System"**
3. Upload HTML file
4. Enter page path (e.g., `pages/about-us.html`)
5. Check "Migrate images to Cloudflare CDN"
6. Click **"📤 Upload & Remaster Page"**

**What Happens**:
- ✅ Shopify scripts/tags removed
- ✅ Images migrated to Cloudflare CDN
- ✅ Header injected
- ✅ SEO enhanced
- ✅ Deployed to R2

### **Option 2: Bulk Scan & Enhance**

1. Visit: `https://www.meauxbility.org/api/pages/scan-and-enhance`
2. Or use POST request to trigger bulk enhancement

**What Happens**:
- Scans all pages in R2
- Adds missing SEO tags
- Injects headers if missing
- Updates existing pages

### **Option 3: Edit Metatags Only**

1. Go to: `https://www.meauxbility.org/admin`
2. Navigate to **"Edit Metatags"** section
3. Enter page path
4. Click **"📥 Load Page"**
5. Edit metatags
6. Click **"💾 Save Metatags"**
