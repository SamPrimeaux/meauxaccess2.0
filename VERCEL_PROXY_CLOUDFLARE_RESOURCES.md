## ?? Request Flow Example

**User uploads file to `meauxxx.com`:**

```
1. Browser ? POST meauxxx.com/api/file/upload
   ?
2. Vercel ? Receives request, proxies to:
   ? meauxmcp.workers.dev/api/file/upload
   ?
3. Cloudflare Worker ? Processes request
   ?
4. Worker ? Writes directly to R2 bucket
   ? R2_WEBSITE bucket (Cloudflare R2)
   ?
5. Response ? Worker ? Vercel ? Browser
   ? File stored in Cloudflare R2!
```

**Key Point:** Vercel never touches the file - it just routes the request!

## ?? What Vercel Actually Does

Vercel **ONLY**:
- ? Routes `meauxxx.com` ? `meauxmcp.workers.dev`
- ? Handles SSL/TLS for your domain
- ? Optional edge caching (can disable)

Vercel **NEVER**:
- ? Stores R2 files
- ? Hosts D1 databases
- ? Caches KV data
- ? Processes requests (Worker does this)
